## 后续更新与采集方式

本次要求的主界面、普通 PDF 问答、Section-Aware 选择、Agent 工具调用和原文引用场景均已收录。后续若替换普通 PDF 截图，应确认侧栏提示使用 Hybrid，保留问题、真实回答和数字引用；若展示引用原文，应保留页码标签，不能将其称为真实章节标题。

先按照 [README 的安装步骤](../../README.md#安装与启动) 启动 Streamlit，使用有权公开的论文和已有真实回答采集：

| 文件名 | 场景 | 应展示内容 |
|---|---|---|
| `pdf-qa.png` | 普通 PDF 问答 | PDF 页数、Chunk 数、问题、回答与页码引用 |

优先复用已有真实会话。新提交问题会产生 DeepSeek API 费用，截图本身不要求重新运行问答。不要把离线测试中的模拟数据作为模型能力展示。

采集前关闭终端和 `.env` 编辑器，隐藏浏览器账户、个人目录、私人问题及私人文档信息。建议只截取应用区域，保证文字清晰。若需遮盖敏感区域，可做明确的局部脱敏，不能改变答案、引用、指标或工具调用结果。展示少量必要原文，避免公开整页论文正文。
